# Tasks API

API REST de gestion de tâches (NestJS 11, TypeScript strict, Prisma + PostgreSQL, Jest). Projet tout juste généré : aucun module métier.

## devflow

Ce projet utilise le plugin devflow. Configuration : `.devflow/config.yml` (surcharges personnelles : `.devflow/config.local.yml`).
