# Catalog Front

Front du catalogue produits (Angular 19, composants standalone, signals, Vitest, Playwright). L'API est servie sous `/api` (proxy de développement : `proxy.conf.json`).

## devflow

Ce projet utilise le plugin devflow. Configuration : `.devflow/config.yml` (surcharges personnelles : `.devflow/config.local.yml`).
