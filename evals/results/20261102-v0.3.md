## Défauts trouvés par les évals et corrigés

| # | Case révélateur | Défaut du plugin | Correction |
|---|---|---|---|
| 1 | `init-symfony` (0,75) | `/devflow:init` proposait `greenfield` pour un dépôt avec un seul commit | `greenfield` seulement si le code applicatif est quasi vide ; le nombre de commits n'est plus un signal |
| 2 | `symfony-bugfix-01-analyse` (0,67) | Le triage lisait le code, diagnostiquait le bug et le classait en S : un seul agent était lancé | Le triage se limite à lister les fichiers ; un bugfix décrit par un symptôme vaut au moins M |
| 3 | `php-legacy-refactor-01-plan` (0,67) | En legacy, l'option « plan de test manuel » permettait de contourner la gate G0 | `tasks/refactor.md` exige des tests de caractérisation **automatisés**, et cette règle prime sur le mode |
| 4 | `php-legacy-feature-01-analyse` (0,67) | La synthèse de `dev-analyse` n'appliquait pas les règles du mode (conventions à imiter, stratégie de test, dette hors périmètre) | Rôle `dev-analyse` ajouté au RESOLVER ; champs obligatoires « Conventions à suivre » et « Stratégie de test » ; traitement de la dette existante précisé dans `modes/legacy.md` |
| 5 | (faux positifs pendant le développement) | `block-secrets` bloquait toute commande dont le texte citait `.env` | Analyse limitée aux commandes qui manipulent des fichiers et aux redirections, heredocs ignorés (84 tests) |
