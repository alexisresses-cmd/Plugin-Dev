# Rapport d'évaluation — v1.0.0 (M6)

- **Date :** 2026-11-03 — Claude Code 2.1.316
- **Méthode :** campagne complète sur `feat/m6-v1`, un run par case, sans sandbox.
  - Commande : `claude plugin eval . --case <case> --scaffold --trust-plugin --no-publish --allow-tools Write Edit`.

## Reprises

| Case | Premier passage | Cause | Reprise |
|---|---|---|---|
| `mixed-feature-01-analyse`, `mixed-feature-01-plan` | non mesurés | run interrompu par la limite d'usage de l'API | 1,00 |

| `wp-legacy-feature-01-analyse` | 0,67 | grader LLM en `focus: last_message`, alors que le contenu attendu était dans le fichier d'analyse | 1,00 |

Aucune correction du plugin n'a été nécessaire au M6. Les deux échecs viennent de l'instabilité des juges LLM. Les corrections des M4 et M5 tiennent toujours :
- refactor : une transformation par tâche ;
- WordPress : tests placés dans le bloc ;
- greenfield : tests écrits avec le code ;
- contrat d'API : tâche isolée.

## Cases sandbox (CI uniquement)

`symfony-feature-01-review`, `php-legacy-refactor-01-cycle` et `symfony-fastlane-01-cycle` exigent `needs-sandbox`. Ils s'exécutent dans `.github/workflows/evals.yml` une fois le secret `ANTHROPIC_API_KEY` configuré sur le dépôt. Ils n'ont **pas encore été mesurés**.
